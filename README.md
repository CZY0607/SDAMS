# SDAMS

SDAMS is a Java Swing desktop application for managing users, class registrations, and payments. This repository starts with the Manager module. Managers can sign in, manage administrator accounts, and view staff and revenue reports. The remaining role screens can be added as the team completes them.

## Run the Manager module

Install JDK 11 or newer. From the project folder on Windows, run `.\run.bat` in PowerShell.
On a fresh run, use the local demo account printed in the terminal. The app stores its local records in `data/`. Use demo records for this class project.

## Contribute

Create a branch for your module and open a pull request into `main`. Coordinate changes to shared classes in `src/sdams/` with the team.
